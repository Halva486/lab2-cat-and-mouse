# CatAndMouse — лабораторная работа №2

Консольное приложение на C# для моделирования игры «Кот и мышь» на круговом игровом поле.

## Требования

- .NET 8 SDK
- Visual Studio 2022 или другая среда с поддержкой .NET 8

## Запуск

Из каталога проекта выполните:

```bash
dotnet build
dotnet run
```

После запуска укажите номер тестового сценария: `1`, `2`, `3` или `4`.

## Файлы сценариев

- `1.ChaseData.txt` — `4.ChaseData.txt`: входные команды игры.
- `1.PursuitLog.txt` — `4.PursuitLog.txt`: файлы, в которые записываются результаты.

Входные файлы содержат размер поля и команды перемещения мыши (`M`), кота (`C`) или вывода текущего состояния (`P`).
